# Instalar Council of Five

## Para las asistentes del workshop

En el chat de Cowork, haz clic en el icono **+** y ve a **Plugins → Añadir plugin**. Se abre el Directorio. Ve a la pestaña **Personal → Cargas locales** y haz clic en el **+**. Selecciona **Añadir marketplace**. Aparece un modal que pide una URL. Escribe exactamente esto:

```
DanielaGallardoio/council-of-five
```

Haz clic en **Sincronizar**. Cowork cargará todos los plugins disponibles de este repositorio. Busca **Council of Five** en la lista y haz clic en **+**. Cuando el icono cambie a una ruedita, el plugin está instalado y listo para usar.

## Comando para compartir en el chat del workshop

```
Marketplace: DanielaGallardoio/council-of-five
```

## Probar que funciona

En cualquier chat de Cowork, escribe:

```
Council of five sobre si me lanzo a freelance ahora o espero seis meses.
```

Si el plugin está bien instalado, Claude responderá presentando 5 personajes con sus filosofías y luego un debate paralelo entre ellos.

## Si algo falla

Lo más probable: un typo al pegar la URL del marketplace, o que tu Cowork no tenga la última versión.

Asegúrate de tener Cowork actualizado y de pegar exactamente `DanielaGallardoio/council-of-five` (sin espacios, sin `https://`, sin nada más).
